About the exam

The Claude Certified Architect — Foundations (CCA-F) is Anthropic's first official technical certification. It validates that a solution architect can make sound production tradeoffs when building with Claude — across Claude Code, the Agent SDK, the Claude API, and the Model Context Protocol (MCP). The practice questions in this kit are written as realistic scenarios that test practical judgement, not recall.

Best for developers, architects, AI engineers, and technical PMs.

Not for exam dumps, pass guarantees, or official Anthropic content.
